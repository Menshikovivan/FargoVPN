## 4.4.0

- Исправлена ошибка `Недействительный CSRF-токен` при запуске массовой рассылки: собственный XHR-обработчик рассылки теперь передаёт session CSRF header.

- Приведены в соответствие с текущей реализацией WebDAV+PostgreSQL контрактные тесты, без изменения рабочей схемы данных.

# Changelog

## 4.3.4 hotfix
- Исправлен установщик: новая установка больше не завершается ошибкой, если API-токен 3x-ui оставлен пустым для последующей настройки через веб-панель.
- Онлайн-проверка 3x-ui по-прежнему обязательна, когда токен уже настроен.

## 4.3.3

- Исправлена автоматическая синхронизация публичной ветки `main` после публикации обновления через веб-панель.
- `main` обновляется одним Git commit через Git database API GitHub без force-push.
- Перед переключением `main` повторно проверяется исходный commit, чтобы не перезаписать параллельные изменения.
- При ошибке синхронизации панель не сообщает об успешной полной публикации обновления.

- Удалены исторические audit/release-note документы из production-архива.
