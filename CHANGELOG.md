# FargoVPN 4.6.11 — Changelog

## Push
- Firefox: создание `PushSubscription` перенесено непосредственно в пользовательский клик после предварительной подготовки Service Worker и VAPID.
- После выдачи разрешения Firefox при необходимости просит повторное нажатие вместо попытки вызвать `subscribe()` из позднего async-continuation.
- Для Firefox используется `Uint8Array` для VAPID applicationServerKey.
- Добавлена проверка Firefox Mozilla Push Service и диагностические подсказки для proxy/VPN/антивируса.
- Chrome/Chromium-поток сохранён.

## Личный кабинет
- Исправлен race при повторном открытии кнопки «Кабинет на сайте»: access-токен больше не становится недействительным после первого запроса и остаётся действительным в пределах TTL.
- HTML/redirect кабинета отдаются без кеширования.
- Повторные запросы одной Telegram-ссылки больше не должны приводить к отображению предыдущей web-сессии.

## Релизная сборка
- Удалены старые audit/diff/release/test артефакты и устаревшие инструкции.
- В архиве оставлены только текущие production-файлы, runtime-утилиты и документация 4.6.11.
