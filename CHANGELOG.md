## 5.0.0 — стабильный релиз, установщик и диагностика

### Дополнительные исправления после QA
- Совместимость обновления с установками 4.x: 5.0.0 принимает старый аргумент `--profile` от прежнего updater и всегда переводит установку на полный профиль.
- В уведомлениях исправлена блокировка кнопок Push: ошибка предварительной подготовки Service Worker/VAPID больше не оставляет «Включить», «Тест», «Выключить» и связанные действия нерабочими; подготовка повторяется непосредственно по пользовательскому клику и показывает причину ошибки.
- Публикация из вкладки «Обновления» теперь синхронизирует в GitHub `main` весь безопасный исходный tree загруженного релизного архива, а не только служебные файлы. Боевые `config.py`/`.env`, базы, логи, кэши и архивы в публичную ветку не попадают.
- Интеграция 3x-ui адаптирована к актуальной структуре API: учитываются `traffic` и `clientStats`, поддерживаются варианты сетевых счётчиков `netIO`/`netTraffic`, а мониторинг показывает расчётную скорость ↓/↑ и расширенные данные узлов.


### Исправлено
- Исправлена отправка рассылки из веб-панели: JSON-ответ `202` больше не открывается как отдельная страница; запуск остаётся внутри панели, показывает состояние и понятные ошибки.
- Фильтры пользователей получили серверный fallback, а сортировка дополнена явной «Датой регистрации» с порядком от ранних к поздним и наоборот.
- Страница диагностики переведена на актуальный PostgreSQL runtime: удалены SQLite PRAGMA/quick_check и показ старого SQLite-пути; добавлены проверка соединения, версии сервера, размера БД и дискового пространства.

### Установщик
- Профиль установки удалён: FargoVPN всегда устанавливается полным вариантом; старое значение `INSTALL_PROFILE` используется только для безопасной совместимости при обновлении.
- Свободное место проверяется на целевом разделе и в каталоге резервных копий; временный каталог проверяется мягко.
- Bootstrap работает одной командой, использует `/var/tmp`, автоматически выбирает `curl`/`wget`, проверяет SHA-256 и очищает временные файлы.
- Итог установщика показывает панель, сокет, PostgreSQL, 3x-ui, внешний Nginx и состояния служб без вывода системного журнала в нормальном успешном завершении.

### GitHub Releases
- Релиз называется `FargoVPN 5.0.0`, тег — `FargoVPN-5.0.0`.
- Описание содержит только changelog текущей версии, одну команду установки и краткую инструкцию обновления.
- Publisher формирует стандартные assets `VPN_Service_Platform_5.0.0_FULL.tar.gz`, `FargoVPN_FULL.tar.gz` и SHA-256-файлы.

### Тесты
- Добавлены регрессионные проверки рассылки, дискового preflight, отсутствия профиля, текущего release notes, bootstrap, assets и PostgreSQL-диагностики.

# FargoVPN 4.7.5

## Исправлено

- Исправлен HTTP 500 в веб-панели при отправке сообщения пользователю: успешная доставка в Telegram больше не превращается в ошибку из-за сбоя вспомогательного `message_log`, журнала сообщений или подготовки ответа UI.
- Журнал исходящих сообщений из веб-панели сделан best-effort: проблемы записи истории логируются, но не отменяют успешно выполненную отправку.
- Аналогично защищена отправка фото/видео из панели.
- Исправлены места, где успешная операция во внешнем сервисе могла возвращать ошибочный 5xx/4xx из-за последующей синхронизации, чтения статуса или служебного логирования.
- Создание, изменение срока и статуса пользователя теперь корректно различают основной результат 3x-ui и вторичные ошибки синхронизации.
- Удаление пользователя больше не сообщает, что 3x-ui отклонила операцию, если удаление в 3x-ui прошло, а локальная запись не удалилась.
- После успешного запуска обновления/отката временная недоступность status-файла больше не превращает запрос на запуск в ошибку.
- Сбой планирования перезапуска служб в диагностике теперь возвращается как контролируемое уведомление панели, а не как необработанный HTTP 500.

## Изменено

- Успешные побочные эффекты теперь имеют приоритет над необязательными действиями наблюдаемости: логирование, обновление кэша и отображение статуса не должны отменять подтверждённую пользователю операцию.
- AJAX-отправка сообщения из раздела «Сообщения» теперь всегда получает явный JSON-ответ `200` при успешной доставке.

## Регрессии

- Добавлены тесты на класс ошибок «операция выполнена → последующая служебная операция падает → UI ошибочно показывает 500».

## 4.6.14

- Полностью переработано восстановление: единая логика для веб-панели, консоли и detached worker.
- Перед каждым восстановлением создаётся и проверяется страховочный полный архив текущего состояния.
- `users-only` теперь восстанавливает только `users`, `payments`, `referral_rewards`; прочее состояние FargoVPN не перезаписывается.
- Полное восстановление проверяет совместимость типа БД 3x-ui (SQLite/PostgreSQL), валидирует полный инвентарь и SHA-256 payload-файлов и выполняет rollback при ошибке/непройденном health-check.
- Усилена защита tar.gz: path traversal, symlink/device, количество элементов, распакованный размер и максимальный размер файла.
- Бэкап теперь явно включает `.env` при наличии, состояние systemd и полный контрольный список файлов; внешний Nginx/L4 по-прежнему не входит.
- В веб-панель добавлен выбор архива и режима восстановления, подтверждение, статус detached restore-worker и блокировка удаления активного архива.
- Консольный установщик показывает точный состав восстановления и делает safety-backup до применения архива.
- Исправлен жёстко зашитый cache-buster Service Worker `4.6.13`: версия берётся динамически из текущего релиза.
