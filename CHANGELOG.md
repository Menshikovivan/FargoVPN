# FargoVPN 4.6.12 — Changelog

## Личный кабинет
- Исправлен HTTP 500 при временной недоступности 3x-ui: кабинет открывается по локальной identity, а live-данные подключаются при следующем успешном запросе.
- Проверка access-token больше не использует `UPDATE ... RETURNING`; поток стал совместимее с PostgreSQL compatibility layer.
- Для существующих БД добавлена автоматическая миграция `cabinet_access_tokens.consumed_at`.
- Повторное открытие Telegram-ссылки кабинета остаётся валидным в пределах TTL.

## Telegram-интерфейс
- Перед выдачей кнопки личного кабинета актуальный Telegram username/display name синхронно записывается из текущего update, чтобы старая запись из восстановления не успевала попасть в кабинет.
- Все пользовательские ссылки и сообщения теперь используют фактическое название раздела `📋 Моя подписка`.
- Исправлена кнопка в напоминаниях о продлении.
- Текст после успешной оплаты теперь ведёт пользователя в `📋 Моя подписка`.

- Архив очищен от старых changelog/release/upgrade/audit/test артефактов и Python cache.
