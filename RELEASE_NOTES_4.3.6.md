# FargoVPN 4.3.6

## Исправление личных сообщений в PostgreSQL

Веб-панель теперь передаёт результат отправки в `message_log.success` как
нативный `BOOLEAN`. Это устраняет `psycopg.errors.DatatypeMismatch`, из-за
которого Telegram мог принять сообщение, а панель затем показывала ошибку
разбора JSON при записи журнала.

## Совместимость восстановленных баз

При запуске миграции FargoVPN проверяет фактический тип
`message_log.success`. Колонки из старых SQLite/PostgreSQL импортов безопасно
приводятся к `BOOLEAN`; `NULL` сохраняется, значения `1/t/true/yes/on`
считаются истинными, остальные — ложными.

## Диагностика панели

Личный чат проверяет `Content-Type` ответа. Если backend вернул HTML или plain
text вместо JSON, администратор увидит понятный HTTP-статус и короткий текст
ответа, а не `JSON.parse: unexpected character`.

## Обновление

Архив поддерживает штатный `install.sh --update-existing /root/vpn_bot`.
Перед обновлением установщик использует существующую конфигурацию и выполняет
идемпотентную миграцию PostgreSQL без замены пользовательских данных.
