## 5.1.14 — 2026-10-09

- Исправлен контракт `launch_detached()` для GitHub publish/update/restore/background workers: `output_path` теперь является частью единого безопасного контракта и пишется в отдельный журнал с правами 0600.
- Внешний контроллер вкладки «Журналы»: больше нет зависимости от inline JavaScript; API возвращает диагностические статусы `ok/empty/not_found/permission/error` и источник журнала.
- Диагностика API стала JSON-only для `/api/*`: ошибки 4xx/5xx больше не должны превращаться в HTML для фронтенда; клиент проверяет статус/Content-Type и показывает фрагмент тела ошибки.
- Исправлен цикл Service Worker/Push: убран `push_reset=<timestamp>` из обычной регистрации, существующая регистрация переиспользуется, автоматическая перезагрузка ограничена одной попыткой на версию в `sessionStorage`.
- Добавлен глобальный перехват `window.onerror` и `unhandledrejection` с записью в журнал панели.
- `diagnose.sh` теперь печатает путь отчёта и итоговую сводку PASS/FAIL.
- Все статические скрипты настроек используют `public_path()`, что проверяется в конфигурации с URI-prefix внешнего Nginx/L4 Router.
