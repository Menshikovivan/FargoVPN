# Changelog

## 5.1.3

### Added
- Новая компактная структура публичного репозитория: runtime находится в `app/`, документация — в `docs/`, проверки — в `tests/`, а корень содержит только публичный bootstrap, README и LICENSE.
- Строгая проверка структуры репозитория в CI.
- Публикация `main` из панели теперь синхронизирует точное дерево архива без искусственного корневого `VERSION`.

### Changed
- Полный установщик перемещён в `app/install.sh`; корневой `install.sh` является только bootstrap.
- Release tags используют формат `vX.Y.Z`.
- Обновление из панели использует `app/install.sh` внутри release-пакета.

### Fixed
- Исправлены синтаксические ошибки Python 3.10/3.11 в Push и веб-навигации.
- Исправлены устаревшие CI-тестовые контракты.
- Прогресс фонового обновления использует реальный статус задачи.

## 5.1.2

Исправления очистки `main` и отображения прогресса обновления.
