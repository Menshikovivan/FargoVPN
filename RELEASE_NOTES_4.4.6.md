# FargoVPN 4.4.6

Точечный релиз исправлений резервного копирования и live-мониторинга журнала бэкапов.

## Резервные копии

- Убран рабочий путь шифрования `age` из текущей доставки.
- Файл, отправляемый в Telegram и загружаемый на Яндекс.Диск, имеет расширение `.tar.gz`.
- Ротация удаляет как новые `.tar.gz`, так и устаревшие legacy-файлы `.tar.gz.age`.

## Live-мониторинг

- Исправлены URL API при работе панели под `WEB_PUBLIC_PREFIX`.
- Добавлено понятное состояние для пустого/недоступного журнала.
- Добавлено автоматическое переподключение после ошибки.

Изменения схемы базы данных не требуются.
