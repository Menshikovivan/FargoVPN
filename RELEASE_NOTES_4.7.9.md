# FargoVPN 4.7.9

## Исправлено

- Регистрация по верному коду приглашения на PostgreSQL: строка владельца кода преобразуется по именам колонок, совместимо с адаптером `CompatRow`.
- `registered_at` записывается как текст с явным приведением времени, соответствующим типу колонки PostgreSQL. То же исправление применено к административной авторизации.
- Добавлена регрессионная проверка регистрации с PostgreSQL-совместимыми строками результата.

Схема базы данных не меняется. Обновление сохраняет ожидающий код статус пользователя, поэтому код можно ввести повторно после установки.
