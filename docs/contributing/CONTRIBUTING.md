# Разработка

Изменения runtime находятся в app/, автоматические проверки — tests/. Установите зависимости tests/requirements-dev.txt в отдельное окружение и выполняйте проверки на синтетических данных. Не импортируйте рабочую конфигурацию и не отправляйте реальные Telegram-сообщения из тестов.

Для исправления ошибки приложите сценарий воспроизведения, ожидаемое и фактическое поведение, регрессионную проверку и её результат. Проверка Python/JavaScript синтаксиса не заменяет тест отрендеренного HTML и интеграцию с PostgreSQL/systemd. Деструктивные сценарии запускайте только в отдельной VM/базе.

В release не должны попадать config.py, базы, backup, ключи, .venv и __pycache__. Версии и changelog согласовываются при сборке выпуска; преждевременное изменение номера не означает готовность пакета.
