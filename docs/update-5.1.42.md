# Обновление до FargoVPN 5.1.42

Пакет предназначен для обновления существующего FargoVPN поверх уже настроенного Nginx L4 Stream Router Mask for 3x-ui. Не переустанавливайте предварительный скрипт и не очищайте рабочую базу для обычного обновления.

## Перед обновлением

1. Сохраните полный резервный архив через панель, скачайте его на отдельный компьютер. Сохраните текущий FULL-пакет и снимок сервера, если он доступен. Бэкап содержит конфиденциальные данные.
2. Убедитесь, что исходная панель и VPN работают, на диске достаточно места для страховочного бэкапа и пакетов. Держите открытым SSH-сеанс.
3. Загрузите на сервер `FargoVPN-5.1.42_FULL.tar.gz` и соответствующий `.sha256` из одной поставки. Проверьте архив:

```bash
sha256sum -c FargoVPN-5.1.42_FULL.tar.gz.sha256
```

Продолжайте только при `OK`. Не устанавливайте архив с несовпадающей суммой.

## Через SSH

В каталоге, куда загружены файлы:

```bash
tar -xzf FargoVPN-5.1.42_FULL.tar.gz
cd FargoVPN-5.1.42
sudo bash ./install.sh --update-existing /root/vpn_bot
```

Если FargoVPN установлен в другом каталоге, замените `/root/vpn_bot` своим фактическим путём. Этот запуск использует извлечённый локальный пакет. Не задавайте `FARGOVPN_USE_REMOTE_LATEST=1`: эта переменная переключает bootstrap на опубликованный GitHub latest, который может отличаться от предоставленного пакета.

## Через веб-панель

Ручная загрузка FULL-архива в панели доступна только защищённой учётной записи издателя. Если у вашей панели этого права нет, используйте описанное выше обновление через SSH; менять своё имя ради получения права не требуется. Для панели издателя: откройте раздел обновления, загрузите тот же FULL-архив и запустите установку. Не запускайте параллельно обновление из SSH и панели. Сохраните сообщение об окончании и журнал. Процент отражает завершение этапов, а не равномерную долю времени: установка зависимостей может занимать большую часть ожидания. Во время остановки веб-службы страница временно теряет связь, сохраняет последний подтверждённый процент и автоматически переподключается. Это ожидаемый этап; не запускайте второе обновление параллельно. После восстановления связи статус сверяется с файлом реальной задачи.

## После установки

1. Проверьте, что панель показывает версию 5.1.42. Перезагрузите вкладку и повторно войдите, если сессия завершилась.
2. Проверьте карточки ранее зарегистрированных неоплаченных и не прошедших PIN клиентов: они не должны отображаться как бессрочные подписчики.
3. В личном чате бота создайте приглашение. Откройте его другим тестовым аккаунтом, включая ранее писавший боту. Проверьте семейный состав, отвязку и предел в четыре аккаунта вместе с владельцем.
4. Для стандартной цены 200 ₽ проверьте предложение оплаты: владелец + один участник — 400 ₽, + два — 600 ₽, + три — 800 ₽. Индивидуальная сумма профиля имеет приоритет над стандартным расчётом. Не оплачивайте тестовый чек на реальном платёжном канале.
5. Проверьте уже действующую VPN-ссылку, доступ к выбранным локациям, личный кабинет, переписку и настройки. Проверьте поступление тестового сообщения боту; лабораторные тесты не подтверждают доставку в вашем Telegram.
6. Просмотрите состояние служб и диагностику:

```bash
sudo systemctl --no-pager --full status vpn-service-web.socket vpn-service-web.service vpn-service-bot.service
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/diagnose.py --app-dir /root/vpn_bot --json
```

Socket-активация допускает ожидающий веб-сервис. Не публикуйте необработанный диагностический отчёт: он может содержать сведения о вашей установке.

## Если обновление завершилось ошибкой

Не нажимайте запуск повторно, пока не проверены статус, журнал и результат автоматического отката. Сохраните страховочный бэкап. Если панель недоступна, используйте SSH для диагностики; не удаляйте базу и конфигурацию. Для ручного восстановления используйте полный бэкап и штатный раздел восстановления после проверки выбранного архива.

Если веб-панель недоступна, а установленный код и его виртуальное окружение целы, восстановление данных можно запустить через SSH:

```bash
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/restore_manager.py --full /absolute/path/backup.tar.gz --actor manual-recovery --json
```

Замените путь приложения и `/absolute/path/backup.tar.gz` фактическими путями. Это **архив резервной копии сервера**, а не FULL-пакет программы. Команда предварительно создаёт страховочный бэкап; не добавляйте `--no-safety`. Восстановление данных сохраняет установленный код, systemd и ключи целевого сервера. Если код или окружение повреждены, сначала используйте сохранённый установочный пакет для восстановления работоспособности; не удаляйте текущую БД и страховочные файлы.
 Users-only восстанавливает пользователей, платежи, рефералы и семейные связи; действующие сессии и приглашения не импортируются.

## Особенность предварительного скрипта

В проверенной лабораторной установке upstream v3.6 при отключённом AWG служба `datasphere-core` завершалась с `226/NAMESPACE`: в её `ReadWritePaths` указан отсутствующий `/etc/amnezia/amneziawg`. Это особенность предварительной установки, не миграция FargoVPN. Только если на вашем сервере подтверждены именно этот статус и отсутствующий каталог, примените:

```bash
sudo install -d -m 0700 /etc/amnezia/amneziawg
sudo systemctl restart datasphere-core
sudo systemctl --no-pager --full status datasphere-core
```

При другой причине сбоя сначала изучите журнал. Переустанавливать upstream или заменять рабочую маршрутизацию для обновления FargoVPN не требуется.

## Правила версии

Бессрочная подписка не переводится автоматически в конечную: это отдельное действие администратора. Уже обещанный срок покупки сохраняется в заявке. Изменение состава семьи после создания заявки требует сверки цены перед подтверждением; приложение не переписывает старую сумму молча. Неоднозначный результат начисления реферального бонуса отправляется на ручную сверку, без повторной автоматической выдачи.

Удаление персональных данных — отдельная подтверждаемая операция. Оно не удаляет ранее скачанные бэкапы, внешние копии и историю Telegram. Формат бэкапа остаётся tar.gz, шифрование автоматически не включается.
