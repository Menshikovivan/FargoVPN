# Агентский отчёт: Telegram семейная привязка

Изменения включены в релиз FargoVPN 5.1.23 из исходного дерева `work/FargoVPN-5.1.20`.

## Реализовано

- В меню Telegram добавлен раздел «Семейный доступ» для владельца профиля.
- Раздел показывает число аккаунтов из 4, позволяет создать одноразовую ссылку на 30 минут и отвязать конкретного участника.
- После привязки уведомляются владелец и новый участник; после отвязки уведомляется удалённый участник.
- Серверная логика проверяет PIN владельца, запрет самопривязки и запрет присоединения аккаунта с уже существующей подпиской. Приглашённый может принять ссылку до PIN; до проверки он не имеет VPN-доступа и не попадает в рассылку. Лимит 4 аккаунта учитывает владельца и защищён транзакционной advisory-блокировкой от параллельных переходов по приглашениям.
- Администрировать профиль может только его владелец; участники не получают кнопки управления чужой семьёй.
- Рассылка выбирает каждого подтверждённого дополнительного Telegram аккаунта как отдельного адресата. Связанный аккаунт владельца не дублируется, неподтверждённые аккаунты исключены.

## Проверки

- Компиляция Python для `app/main.py`, `app/services/billing.py`, `app/broadcast_manager.py` прошла.
- Целевые статические assertions прошли: кнопки и callback-действия меню, deep-link, ограничение в 4, блокировка изменений членства, отвязка и включение участников в адресаты рассылки.
- Агентские статические проверки прошли. Итоговый совместный набор на Debian 12: 44 passed, 1 skipped, включая браузерные проверки панели.
- Живой Telegram не подключался. PostgreSQL интеграционная проверка для этой итерации не завершена из-за прав на отдельную тестовую БД VM; предыдущая миграция 5.1.22 и семейная тарификация отдельно тестировались на PostgreSQL.
