# Безопасность FargoVPN

## Поддерживаемая версия

Текущий целевой релиз проекта: **5.1.6**.

## Секреты

Никогда не публикуйте:

- Telegram Bot Token;
- GitHub Personal Access Token;
- ключи и пароли 3x-ui;
- пароль PostgreSQL;
- `WEB_SECRET_KEY` и `WEB_PASSWORD_HASH`;
- VAPID private key;
- cookies и действующие session-токены;
- production `config.py`, `.env` и базы данных.

Если секрет хотя бы раз попал в Git или был опубликован в архиве, считайте его скомпрометированным и перевыпустите независимо от того, удалён ли файл из текущего `main`.

## Утечка в Git-истории

Удаление файла из текущей ветки не удаляет его из истории. Перед переписыванием истории создайте зеркальный backup репозитория. Для удаления файлов или замены строк используйте `git filter-repo` либо BFG Repo-Cleaner. После переписывания понадобятся force-push веток/тегов, а старые локальные клоны нужно считать недоверенными и клонировать заново.

Пример с `git filter-repo`:

```bash
git clone --mirror git@github.com:Menshikovivan/FargoVPN.git FargoVPN.git
cd FargoVPN.git
# Пример: удалить скомпрометированный файл из всей истории.
git filter-repo --invert-paths --path config.py --force

git remote -v
git push --force --all origin
git push --force --tags origin
```

Эти команды **не следует запускать без отдельного подтверждения владельца репозитория**.

## Сообщение об уязвимости

Не публикуйте токены, пароли и эксплуатационные детали уязвимости в публичном Issue. После включения GitHub Security Advisories используйте private advisory. До этого сообщайте владельцу репозитория через GitHub приватным способом.

## Безопасная установка

Проверяйте источник релиза и SHA-256. Не запускайте непроверенный `install.sh` и не восстанавливайте backup на production без предварительного просмотра его содержимого.
