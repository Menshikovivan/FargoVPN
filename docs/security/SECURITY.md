# Безопасность

Не публикуйте config.py, DATABASE_URL, Telegram/GitHub tokens, пароли, VAPID private key, ключи сессий, базы и резервные копии. Backup является конфиденциальным архивом; автоматическое шифрование обычного tar.gz не обещается. Ограничивайте доступ к нему и храните отдельную проверенную копию.

Панель предназначена для доверенных администраторов. Используйте HTTPS, уникальный пароль, актуальные зависимости и ограниченный административный доступ. Для сообщения об уязвимости свяжитесь с владельцем установки по известному вам приватному каналу. Не прикладывайте реальные токены к публичным issues; воспроизводите на синтетических данных.

Маскирование журналов снижает риск утечки известных секретов, но не гарантирует удаления любого персонального текста. Перед передачей отчёта проверьте содержимое. Изоляция тестов, резервные копии и минимальные права обязательны при испытании обновления/восстановления.
