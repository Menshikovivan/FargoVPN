# Первые шаги

## 1. Установите сервер

Используйте команду быстрого установщика из главной страницы проекта.

## 2. Завершите настройку

Заполните параметры Telegram, PostgreSQL, 3x-ui, публичного URL и оплаты в веб-панели.

## 3. Проверьте 3x-ui

Убедитесь, что API доступен и выбранные inbound/client данные отображаются в панели.

## 4. Проведите тестовый пользовательский сценарий

Регистрация → оформление подписки → выдача ссылки → проверка подключения → просмотр статистики.

## 5. Проверьте обновление

Перед production-обновлением создайте резервную копию и проверьте доступность раздела «Обновления».
