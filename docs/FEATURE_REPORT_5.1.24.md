# FargoVPN 5.1.24 — готовность к установке

Исправлены семейные приглашения, включая пользователей, уже зарегистрированных в боте, и расчёт семейной цены при нажатии inline-кнопки оплаты. При отправке чека сумма проверяется повторно: если цена поменялась после выдачи реквизитов, чек не регистрируется, а бот показывает актуальную стоимость.

Telegram-рассылка администратора теперь использует единый список получателей с веб-панелью, включая разрешённых участников семейных профилей. Улучшена адаптивная компоновка веб-панели и добавлен браузерный тест размеров экрана.

Перед установкой на сервер с FargoVPN создайте независимую резервную копию и обновляйтесь поверх установленного FargoVPN, который следует за базовым Nginx L4 Stream Router Mask for 3x-ui. Архив содержит только файлы FargoVPN, сам скрипт-основа не заменяется.
