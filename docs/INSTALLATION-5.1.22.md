# Обновление FargoVPN до 5.1.22

Пакет предназначен для обновления FargoVPN поверх уже установленного базового Nginx L4/3x-ui. Перед обновлением сохраните каталог приложения, `config.py` и PostgreSQL backup вне сервера. Проверьте архив по `SHA256SUMS-5.1.22.txt`.

```bash
sha256sum --ignore-missing -c SHA256SUMS-5.1.22.txt
tar -xzf FargoVPN-5.1.22_FULL.tar.gz
cd FargoVPN-5.1.22
bash ./install.sh --update-existing /root/vpn_bot
```

Если FargoVPN установлен в другом каталоге, подставьте его путь. Установщик работает с локальным архивом и не меняет базовый установщик Nginx L4/3x-ui.

После обновления войдите в веб панель и откройте карточку основного пользователя в `/users/id/<TG_ID>`. Укажите индивидуальную сумму за период, если нужна, либо оставьте поле пустым для стандартного тарифа, умноженного на число Telegram аккаунтов.

Нажмите «Создать ссылку привязки на 30 минут» и передайте ссылку дополнительному пользователю. Он должен открыть её со своего Telegram аккаунта, начать диалог с ботом, пройти проверку PIN-кода, затем повторно открыть ссылку. Ссылки одноразовые. У дополнительного аккаунта не должно быть своей XUI-подписки. После привязки перепроверьте сумму в карточке пользователя.

Резервные копии до обновления сохраняйте до ручной проверки панели, бота, одной оплаты и подключения VPN. Миграция создаёт self-link существующим пользователям и не меняет сроки подписок и историю платежей.
