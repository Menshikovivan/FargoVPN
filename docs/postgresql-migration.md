# PostgreSQL и миграция

Текущий installer использует PostgreSQL, подготавливаемый `app/scripts/setup_postgresql.sh`. Существующие установки SQLite обрабатываются штатным migration flow установщика и `migration_tool.py`; ручное копирование SQLite поверх PostgreSQL не переносит данные.

Перед миграцией сделайте полный backup и сохраните существующий config.py приватно. Не запускайте самостоятельно `--reset-target` на рабочей базе: этот режим предназначен для контролируемого потока миграции. Убедитесь, что выбран правильный каталог установки, в отчёте миграции нет ошибок и службы запускаются. Затем проверьте пользователей, семейные связи и платежи через панель. Не удаляйте исходную базу до проверки.

При ошибке сохраните журнал и отчёт миграции, остановите дальнейшие изменения и используйте штатный rollback/backup. Никогда не публикуйте DATABASE_URL или дамп. Проверка миграции в тестовой среде не гарантирует совпадение расширений, прав и версии PostgreSQL на конкретном сервере.
