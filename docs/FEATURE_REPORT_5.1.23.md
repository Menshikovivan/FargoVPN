# FargoVPN 5.1.23 — отчёт обновления

Дата: 18 октября 2026 года. Основа: FargoVPN 5.1.22. Пакет рассчитан на обновление поверх установленного FargoVPN, развёрнутого после базового Nginx L4/3x-ui.

## Изменения

- В кабинете Telegram владелец профиля может создать семейную ссылку на 30 минут и отвязать отдельный аккаунт.
- Подтверждённые семейные аккаунты получают личные рассылки FargoVPN; дубли владельца и неподтверждённые аккаунты исключены.
- Лимит профиля — четыре Telegram аккаунта вместе с владельцем. Серверная блокировка защищает лимит при одновременном использовании приглашений.
- Кнопка в панели теперь содержит CSRF-токен, создаёт ссылку и отправляет её в личный чат владельца. Панель сообщает об успешной доставке или показывает причину отказа и резервную ссылку.
- На мобильной ширине карточки пользователя и мониторинга остаются в одной колонке.
- Процент обновления показывает последнее подтверждённое установщиком значение, а не анимационную оценку.

## Проверки

- Агентские целевые статические проверки: привязка, отвязка, лимит, доставка рассылок, POST/CSRF панели и прогресс обновления.
- Изменения Python и браузерного теста скомпилированы; JavaScript проверен Node.
- Linux Debian 12 VM: целевой набор на точном распакованном релизном архиве прошёл: 44 passed, 1 skipped за 69.35s. Проверены семейная привязка, панель, рассылки, PIN-статусы, кабинет и релизные контракты, включая headless browser-panel тесты.
- Python compileall и Node syntax check прошли. PostgreSQL миграция семейного сценария в этой итерации не завершена: изолированная БД VM не дала рабочие права приложению; предыдущая 5.1.22 миграция тестировалась отдельно.

## Ограничения

Боевой Telegram и сервер пользователя не подключались. Привязка по ссылке может пройти до PIN-проверки, но участник получает подписку и рассылки только после проверки PIN. Профили с уже существующей VPN-подпиской присоединить нельзя. Семейные аккаунты используют VPN доступ владельца. Сумма семейной подписки остаётся расчётом 5.1.22: множитель по числу аккаунтов либо персональная сумма, заданная в панели.
