# Визуальная проверка

В release-архив не включены снимки рабочего сервера. Для проверки используйте синтетические данные и фиксируйте версию, размер viewport и состояние страницы. Проверяйте мобильные таблицы, формы, меню, уведомления об ошибке и клавиатурный фокус.

Материалы текущего аудита поставляются отдельно от установочного пакета. Они показывают тестовые страницы, а не состояние вашей установки. Снимок одной страницы не подтверждает доступность всего интерфейса, работу iOS/WebKit или корректность платежей.
