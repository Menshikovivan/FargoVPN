# Скриншоты

Каталог предназначен для публичных скриншотов GitHub README.

Нужны минимум следующие изображения:

- `overview.png` — обзор панели на десктопе;
- `overview-mobile.png` — мобильный вид панели;
- `users.png` — список пользователей;
- `settings.png` — настройки;
- `updates.png` — обновления и публикация релиза.

Пока реальные изображения не добавлены, README не ссылается на вымышленные файлы.
