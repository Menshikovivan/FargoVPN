# Эксплуатация FargoVPN

Штатная установка разворачивает `app/` в `/root/vpn_bot` (или выбранный каталог). Перед обновлением сохраните полный backup через панель и проверьте, что архив скачан. Архив содержит конфиденциальные данные: храните его с ограниченным доступом.

Проверяйте `vpn-service-web.socket`, `vpn-service-web.service`, `vpn-service-bot.service` через systemctl. Активный socket при ещё не запущенном web service допустим: он активирует службу по обращению. Пустой Telegram token означает, что готовность бота не подтверждена; это не проверка отправки сообщений.

Read-only диагностика установленной системы:

```bash
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/diagnose.py --app-dir /root/vpn_bot --json
```

Замените путь, если выбран другой каталог. Диагностика создаёт приватный отчёт; не публикуйте необработанные конфиги или резервные копии. При неясном результате запуска фоновой задачи сначала проверьте её статус и журнал: повтор может дублировать действие.

Обновление, восстановление и rollback запускаются из соответствующих разделов панели. Процент установки — отметки завершённых этапов, а не прогноз оставшегося времени. Успех установки ещё не подтверждает работу внешнего Telegram, оплат, DNS/ACME и клиентских устройств. После обновления проверьте вход в панель, личный чат бота и тестовое подключение.

FargoVPN устанавливается поверх предварительно настроенного Nginx L4 Stream Router Mask for 3x-ui. Изменения Nginx/UFW/NAT выполняйте по документации этого проекта; не заменяйте рабочую маршрутизацию непроверенным примером.
