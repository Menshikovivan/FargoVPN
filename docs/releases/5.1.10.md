# FargoVPN 5.1.10

## Исправление консольного установщика

5.1.9 могла остановить обновление на проверке 3x-ui, если в системе отсутствовал бинарник `timeout`. 5.1.10 больше не зависит от этой внешней команды: установщик использует собственный bash timeout helper, а `coreutils` проверяется как системная зависимость.

Консольный установщик не выполняет GitHub write-операций. Публикация `main`, tag, Release и assets по-прежнему выполняется только worker веб-панели после загрузки архива администратором.
