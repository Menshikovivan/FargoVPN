# FargoVPN 5.1.3

## Что изменилось

- Репозиторий получил компактную структуру: в корне остаются только `install.sh`, `README.md` и `LICENSE`.
- Runtime-код, installer, static, migrations и systemd-шаблон находятся в `app/`.
- Документация вынесена в `docs/`, тесты — в `tests/`, вспомогательные скрипты — в `scripts/`.
- Публикация из панели формирует точное дерево `main` и удаляет файлы, которых больше нет в новой версии.
- После установки выполняется автоматическая проверка/очистка GitHub `main`, если настроен GitHub publisher.
- Исправлены Python 3.10/3.11 syntax errors, из-за которых CI падал на Push и веб-панели.
- Обновлён CI под новую структуру и матрицу Python 3.10–3.13.
- Улучшено отображение этапов фонового обновления.

## Обновление

Рекомендуемый способ — установить `FargoVPN_FULL.tar.gz` через раздел «Обновления» веб-панели. Перед обновлением штатный механизм создаёт backup и сохраняет production-конфигурацию.
