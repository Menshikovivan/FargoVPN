# FargoVPN 5.1.19

Дата: 2026-10-09

## Исправления CI
- Возвращена корректная обработка HTTPException для обычных HTML-маршрутов панели: ожидаемые 403/404 больше не превращаются в необработанную ошибку.
- Тесты публикации изолируют каталог обновлений, статусы, журналы и историю в `tmp_path`; CI не пытается писать в `/var/lib/vpn-service`.
- Проверка bootstrap-установщика учитывает release-independent `main/install.sh` и локальный путь установки FULL-архива, не привязываясь к необязательному `--progress-bar`.
- GET-only тест bootstrap запускает изолированную копию с отключённой только root-проверкой; продакшен-установщик по-прежнему требует root.
- Исправлены CI-тесты и фикстуры, чтобы их поведение не зависело от root-прав runner.
