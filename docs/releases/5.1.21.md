# FargoVPN 5.1.21

Исправленная локальная сборка на основе предоставленной 5.1.20. Подробные результаты Linux-приемки находятся в комплекте отчетов.

Исправлены кабинет и prefix URL, labels/клавиатурные вкладки, выбор Nginx хоста и HSTS, доверие proxy headers на Unix socket, лимиты restore и отзыв сессий при смене credentials. Предобновленческий снимок включает .venv и PostgreSQL; перед снимком/откатом останавливаются sockets, timers и writers. Откат БД транзакционный. Bootstrap не меняет пароль чужой роли.

Восстановление из backup теперь переносит данные в доверенную текущую схему и разрешенные бизнес-настройки. Архивный SQL, код, systemd, .env и настройки запуска сервисов не исполняются и не применяются. Несовместимая схема/нарушения FK отклоняются. Для восстановления старой версии программы сначала отдельно установите нужную доверенную версию. Совпадение типа БД 3x-ui обязательно.

После обновления требуется повторный вход. Снимки с .venv требуют больше места. Проверьте наличие свободного места и независимого backup перед обновлением.
