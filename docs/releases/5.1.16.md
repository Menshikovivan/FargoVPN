# FargoVPN 5.1.16

Дата: 2026-10-09

## Исправления

- Исправлена ложная блокировка публикации GitHub сообщением «Другая публикация GitHub уже выполняется».
- Для legacy `status.json` без поля `unit` публикация теперь сверяется с реальным процессом `publish_worker.py --job-id ...`.
- Если worker ещё работает, параллельная публикация корректно блокируется. Если worker уже завершился или был убит при перезапуске веб-службы, зависшее состояние переводится в `failed` и новая публикация становится доступна.
- Добавлены регрессионные тесты для старых статусов без systemd-unit.
