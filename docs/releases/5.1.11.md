# FargoVPN 5.1.11

## Исправления веб-панели

### Сообщения
Отправка сообщения администратором больше не приводит к полной перезагрузке страницы. Исправлен синтаксически повреждённый generated JavaScript и сохранён live-echo отправленного события в чат.

### Журналы
Страница журналов теперь отрисовывается быстро и получает данные асинхронно. Переключение источника, количества строк, уровня и текстового фильтра работает без reload; результат и ошибки видны сразу.

### GitHub
Проверка авторизации GitHub теперь выполняется через AJAX с явным статусом и JSON-ошибками. Перед загрузкой релиза проверяется файл `.tar.gz`, а XHR upload получает понятный локальный отклик.
