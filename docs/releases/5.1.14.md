# FargoVPN 5.1.14

## Основные исправления

- GitHub publish больше не падает на `launch_detached(..., output_path=...)`; контракт фонового запуска унифицирован для всех мест вызова.
- «Журналы» больше не зависят от inline JavaScript и показывают причину отсутствия данных: файл не найден, нет прав, журнал пуст или ошибка чтения.
- Диагностика гарантирует корректный JSON для API, сохраняет отчёт на сервере и возвращает ссылку на скачивание.
- Устранён цикл перезагрузок «Настроек» из-за Service Worker; регистрация Push переиспользуется и больше не получает случайный query string на каждом открытии.
- Управление Push восстановлено и работает в prefix-aware режиме за внешним Nginx/L4.
- `window.onerror` и `unhandledrejection` записываются в серверный журнал панели.
