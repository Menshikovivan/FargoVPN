# FargoVPN 5.1.12

Релиз исправляет регрессию веб-панели 5.1.11 и добавляет системные проверки AJAX/CSP/GitHub.

## Ключевые изменения

- Исправлена внешняя CSP-политика Nginx/L4, блокировавшая inline-контроллеры страниц.
- Сообщения и журналы работают без перезагрузки страницы и показывают ошибки с повтором.
- GitHub authorization check работает через JSON API и проверяет токен, репозиторий, права записи и целевую ветку.
- Исправлена очистка legacy PostgreSQL `telegram_update_dedup`.
- Укреплён systemd запуск веб-панели.
