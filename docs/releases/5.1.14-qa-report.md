## Nginx L4 / Router compatibility

Внешний router проверен по исходнику: основной HTTPS-трафик проходит через `ngx_stream_core_module`/`ssl_preread` и передаётся в HTTP backend через Unix socket `/dev/shm/nginx-http.sock`; конфигурация использует `proxy_protocol`. FargoVPN не вмешивается в stream-layer: `nginx_panel_guard.py` выбирает уже существующий HTTPS/L7 server, добавляет только managed URI-prefix location, выставляет `X-Forwarded-Prefix`, скрывает конфликтующую CSP и проксирует к тому же Unix socket. Это делает панель совместимой с установкой Router/L4 без изменения маршрутизации Xray/Reality/xHTTP.
