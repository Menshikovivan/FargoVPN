# FargoVPN 5.1.7

## GitHub-публикация из панели

Версия 5.1.7 закрепляет веб-панель как штатный интерфейс релизного процесса. Архив новой версии загружается в разделе «Обновления», после чего фоновый publisher выполняет синхронизацию публичного `main`, создаёт tag и GitHub Release, загружает release assets и checksum-файлы и выполняет итоговую проверку через API GitHub. Ручные коммиты/ветки/релизы через внешний GitHub-инструмент для штатного процесса не требуются.

## Исправление загрузки

Исправлена ошибка inline JavaScript во вкладке «Обновления». Некавыченный ключ `health-check` ломал весь скрипт страницы, поэтому обработчик XHR загрузки архива не срабатывал: браузер выполнял обычную отправку формы и перезагружал страницу. Теперь отображается прогресс передачи файла и отдельный прогресс публикации GitHub.

## Настройки GitHub

Добавлен безопасный bootstrap-сценарий: пока GitHub token ещё не сохранён, главная административная панель может открыть «Настройки GitHub», указать owner/repository/token и параметры Release. После сохранения конфигурация используется самой панелью; дальнейшие публикации выполняются через загрузку архива в веб-интерфейс.
