# FargoVPN 5.1.9

## Основные исправления

### Консольный установщик

Диагностика запускается через `scripts/diagnose.sh`; отчёт создаётся в приватном файле с маскировкой секретов.
Установка больше не инициирует публикацию или синхронизацию GitHub. После smoke-теста 3x-ui установщик выполняет только локальные проверки, timed systemd/health cleanup и завершает установку. Долгие операции печатают номер шага, ожидаемое действие и таймаут.

### GitHub из панели
Кнопка публикации привязана напрямую к click, загрузка использует XHR progress, а network/API validation выполняется в фоне publisher worker. Статус и лог сохраняются на диске; поддерживается отмена.

### Журналы
Добавлены источники системного application log, update launcher, GitHub publisher, Push и фильтры/скачивание/автообновление. Чтение файлов ограничено tail-размером.
