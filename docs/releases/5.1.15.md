# FargoVPN 5.1.15

Исправлена ошибка `Другая публикация GitHub уже выполняется`, возникавшая после перезапуска веб-панели при сохранённом незавершённом `publish/status.json`.

## Что изменено
- `publish_job_busy()` проверяет реальный transient systemd worker.
- Мёртвый worker автоматически переводит persisted job в `failed`.
- Legacy stale state очищается по `PUBLISH_STALE_JOB_SECONDS` (1800 секунд по умолчанию).
- Живой worker по-прежнему блокирует второй запуск.
- Добавлены regression-тесты на live/dead worker.
