# FargoVPN 5.1.4

## Что изменилось

### Обновление панели
- Прогресс установки отображается по этапам: проверка, скачивание, распаковка, установка, миграция, перезапуск служб и health-check.
- Во время долгих операций шкала не замирает на одной цифре: она плавно показывает выполнение текущего этапа, не выдавая следующий этап за завершённый.
- После восстановления веб-службы панель автоматически повторно подключается к задаче и после `completed` сама открывает актуальную страницу.

### Публикация в GitHub
- Передача архива на панель и серверная публикация в GitHub теперь разделены.
- После передачи архива отображается отдельный живой прогресс GitHub.
- Видны шаги синхронизации `main`, создания Release, загрузки assets и финальной проверки.
- Публикация выполняется отдельным systemd-процессом и не зависит от жизненного цикла HTTP-запроса.
