# FargoVPN 5.1.8

## Консольная установка

Если архив уже загружен на сервер и распакован, корневой `install.sh` запускает именно этот локальный `app/install.sh`. Он не подменяет пакет архивом из GitHub Releases/latest. Это позволяет впервые установить новую версию до её публикации через веб-панель.

## GitHub-публикация из панели

Загрузка релизного `.tar.gz` выполняется через XHR с отдельным progress загрузки. После приёма архива запускается detached publisher worker, который подтверждает запуск, пишет постоянный статус и отдельный launcher log. Панель продолжает polling даже после перезагрузки.

Перед публикацией выполняется проверка GitHub token и права push к репозиторию. Далее автоматически синхронизируются `main`, создаются tag/Release и assets, после чего выполняется финальная проверка GitHub API.
