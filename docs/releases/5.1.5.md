# FargoVPN 5.1.5

## Что изменилось

5.1.5 исправляет фоновое обновление из веб-панели и CI проекта.

- обновление больше не должно зависать на 2%;
- журнал запуска worker сохраняется до импорта Python-модулей;
- после старта worker статус обновления подтверждается автоматически;
- CI использует зависимости из `app/requirements.txt`;
- GitHub publisher и `publish_worker.py` входят в единое дерево релиза.

## Обновление

Установите архив `FargoVPN_FULL.tar.gz` через раздел «Обновления» веб-панели.
