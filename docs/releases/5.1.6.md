# FargoVPN 5.1.6

## Что исправлено

### Фоновое обновление
Worker больше не запускается с искусственной задержкой перед подтверждением. Панель ждёт устойчивое подтверждение фактического запуска отдельного systemd-процесса до 6 секунд. Если процесс не стартовал, задача переводится в `failed` с явной причиной и путём к launcher-журналу вместо зависания на 2%.

### Журнал обновления
Сохранён отдельный `update-launcher.log`, в который попадают ошибки оболочки/systemd launcher до появления обычного `update.log`.

### История изменений
Во вкладке «Обновления» отображается локальная история последних предыдущих версий из `app/CHANGELOG.md`. История не требует сетевого запроса к GitHub.

### Откат из панели
Ручные функции rollback/downgrade удалены из веб-панели. Защитная автоматическая процедура возврата внутри установщика при неудачном обновлении сохранена для безопасности.
