# Установка FargoVPN 5.1.23

Пакет предназначен для обновления FargoVPN, установленного поверх базового скрипта Nginx L4/3x-ui. Перед обновлением сохраните каталог приложения, `config.py` и PostgreSQL backup вне сервера. Проверьте архив по `SHA256SUMS-5.1.23.txt`.

```bash
sha256sum --ignore-missing -c SHA256SUMS-5.1.23.txt
tar -xzf FargoVPN-5.1.23_FULL.tar.gz
cd FargoVPN-5.1.23
bash ./install.sh --update-existing /root/vpn_bot
```

Если FargoVPN установлен в другом каталоге, замените `/root/vpn_bot` на его путь. После обновления откройте кабинет Telegram основного пользователя и нажмите «Семейный доступ». Для приглашения ссылку нужно отправить присоединяемому пользователю; она действует 30 минут. Для отвязки выберите нужный аккаунт в семейном доступе. В сумме разрешено до четырёх аккаунтов, включая владельца.

Кнопка семейной ссылки в карточке пользователя веб-панели также отправляет приглашение владельцу в Telegram. Если бот не может написать владельцу, панель покажет причину и ссылку для передачи вручную.

Сохраните backup до проверки панели, бота, рассылки и VPN-подключения. Реальная доставка зависит от того, что каждый участник начал диалог с ботом и не заблокировал его.
