# FargoVPN 5.1.22 — отчёт изменения

Дата: 18 октября 2026 года. Основа — локально проверенная 5.1.21. Назначение: показывать реальные статусы PIN/оплаты и поддержать несколько Telegram аккаунтов в одном VPN профиле с семейной ценой.

## Что изменилось

- Для контакта без пройденного PIN бот и панель показывают «Не прошёл проверку PIN-кода». Для прошедшего PIN без VPN-профиля — «Подписка не оплачена». «Бессрочная» отображается только при реальном UUID, email или sub_id. Истёкшие и выключенные подписки сохраняют свои отдельные статусы.
- Миграция при старте создаёт self-link для уже известных аккаунтов, не трогает их сроки, статусы регистрации, платёжные строки и XUI-профили. Старые пользователи со статусом ожидания PIN автоматически увидят правильную пометку; пустые оболочки с `expiry_time=0` станут «не оплачено».
- В карточке пользователя администратор создаёт ссылку для второго Telegram аккаунта. Дополнительный пользователь открывает её сам в боте; аккаунт должен пройти текущую PIN-проверку. Ссылка одноразовая, живёт 30 минут и хранится как хеш. Профили с собственной XUI подпиской привязать нельзя.
- Один подтверждённый аккаунт стоит стандартную цену, два — 2×, три — 3×. Один владелец сохраняет одну VPN подписку и получает стандартные дни; множитель относится к сумме, не к сроку. Администратор может задать итоговую индивидуальную сумму за период; пустое поле включает автоматический расчёт.
- Сумма фиксируется в записи платежа при отправке чека и применяется для OCR и административного уведомления. Карточки панели, Telegram CRM и напоминания используют один расчёт.

## Границы

Публичный Telegram, сторонние платежные провайдеры и боевой сервер пользователя не подключались. Дополнительные аккаунты делят VPN доступ основного профиля; отдельный XUI клиент не создаётся. Участник с существующим VPN профилем отклоняется, его нужно сначала вручную разобрать в панели. Персональная сумма — итоговая сумма за период, она заменяет семейное умножение.
