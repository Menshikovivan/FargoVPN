# UI и индикатор обновления: независимая проверка

Область FargoVPN 5.1.23: мобильная сетка админ-панели и достоверность процента на `/updates`.

## Найдено и исправлено

- В мобильной ширине до 560 px общий `.grid` переключается на одну колонку, но карточки с классами `.half`, `.wide`, `.side`, `.full` и `.metric` сохраняли desktop `grid-column: span N`. Это создавало неявные колонки и могло сжимать/растягивать карточки на `/users/id/<tg_id>`, `/users` и страницах диагностики/мониторинга. Добавлено правило, сбрасывающее такие карточки в одну колонку.
- `/updates`: JS раньше плавно увеличивал число процента до условного предела текущего этапа (`softCaps`), даже если установщик долго не присылал новый статус. В результате визуальный процент выглядел как измеренное продвижение, хотя сервер его не подтверждал. Теперь числовой процент и ширина заливки совпадают с последним значением из статуса задачи; анимированная заливка остаётся индикатором активности. Время выполнения продолжает обновляться отдельно.

## Проверки

- 2 целевых теста пройдены: процент использует только серверный статус; мобильная сетка сбрасывает desktop spans.
- `py_compile` прошёл для `app/webapp.py` и `tests/test_browser_panel.py`.
- Node `--check` прошёл для фактически извлечённого скрипта `/updates` и `app/static/panel.js`.
- Итоговый Linux Debian 12 headless browser-panel и целевой набор прошли: 44 passed, 1 skipped. Числовой тест оставляет 42% неизменными после ожидания, пока сервер не прислал новый статус.
