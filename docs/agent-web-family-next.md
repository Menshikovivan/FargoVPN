# Агентский отчёт: веб-привязка семейного аккаунта

Исправлены форма и обработчик семейной ссылки в веб-панели FargoVPN 5.1.23.

- Причина неработающей кнопки: форма POST не содержала CSRF-токен. `require_auth` отклонял запрос с HTTP 403 ещё до создания ссылки.
- Форма теперь отправляет CSRF-токен с сессии администратора.
- Маршрут проверяет, что целевой аккаунт — основной Telegram-профиль, затем создаёт одноразовую ссылку на 30 минут и отправляет её в Telegram чат владельца через Bot API `sendMessage`.
- Панель показывает подтверждение отправки. При недоступности чата/ошибке Telegram показывает причину и резервную ссылку для ручной передачи. Токен не пишется в аудит-журнал.
- Добавлены целевые регрессионные тесты формы и маршрута.

Проверки: 2 целевых теста прошли; изменения также вошли в совместный Linux-набор (44 passed, 1 skipped). `py_compile` прошёл.
