# FargoVPN 4.5.2

## Основные изменения

- Удалена установка Nginx и собственный L4/TLS flow из FargoVPN. Внешний reverse proxy/L4/3x-ui настраивается отдельным проектом.
- Добавлен compatibility-layer для уже установленного внешнего Nginx: FargoVPN публикуется отдельным случайным `/fargovpn-admin-.../` URI на том же HTTPS virtual host, где находится 3x-ui; собственная конфигурация L4/443/TLS FargoVPN не создаётся.
- Для Unix socket автоматически выбирается группа worker-процесса внешнего Nginx, чтобы проксирование не завершалось ошибкой доступа.
- Бэкап: один systemd-сервис `vpn-service-backup.service`, доставка только в Telegram.
- Формат: обычный `.tar.gz`, без `.age`. Архив содержит FargoVPN PostgreSQL, пользовательские данные, 3x-ui DB/config, systemd и необходимые persistent-файлы.
- Архив проходит проверку структуры и SHA-256. Для Telegram используется деление на безопасные части до 45 MB.
- В установщике появилась вкладка/пункт «Восстановление»: папка с частями → автоматическая сборка → «только пользователи» или «вся система».
- Восстановление выполняется через staging PostgreSQL с проверкой количества `users` до переключения рабочей БД; предыдущая БД сохраняется для отката.
- Веб-раздел «Журналы → Процесс бэкапа · live» получает состояние непосредственно от единственного backup worker.

## Ограничение

Конфигурация внешнего reverse proxy/L4 и его TLS-сертификаты не принадлежат FargoVPN и поэтому намеренно не восстанавливаются этим проектом.
