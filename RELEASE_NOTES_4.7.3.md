# FargoVPN 4.7.3

## Добавлено
- Полная история общения пользователя с FargoVPN в веб-панели: входящие, исходящие и служебные события.
- Унифицированный журнал исходящих Telegram Bot API вызовов.
- Фильтрация по направлению (`входящие / исходящие / система`) и типу (`обычные / служебные`).
- Поиск по тексту, Telegram ID и username.
- Пагинация истории сообщений без фиксированного лимита 500 записей.
- Статус доставки (`доставлено / ошибка / получено / неизвестно`) и текст ошибки для исходящих событий.
- Асинхронная очередь пакетной записи журнала.
- Маскирование секретов и приватных ссылок подписки перед сохранением.

## Исправлено
- Убраны пробелы в журналировании для массовых рассылок, напоминаний и обновления ссылок подписок, которые выполнялись отдельными worker-процессами.
- Входящие Telegram Update теперь журналируются на уровне Dispatcher, а не только в двух конкретных router-ветках.
- Служебное сообщение очистки старой Telegram-клавиатуры также сохраняется в истории.
- Исправлена PostgreSQL-совместимость обновления compact unread state (`GREATEST(...)`).
- Не-сообщения вроде `sendChatAction` больше не отображаются как отправленные сообщения.
- Исправлено отображение старых событий после расширения схемы `user_events`.

## Совместимость
- Миграция добавляет только новые nullable/defaulted поля и индексы; существующие сообщения не удаляются.
- Backup/restore остаются совместимыми, БД бизнес-функций не меняется.
