# FargoVPN 4.4.2

## Яндекс.Диск в веб-панели

- Кнопки «Проверить подключение» и «Тестовая загрузка» переведены на отдельные JSON API-эндпоинты с явной передачей CSRF-токена.
- Сетевые проверки выполняются вне event loop через `asyncio.to_thread`, поэтому панель не блокируется на время WebDAV-запроса.
- Результат проверки сразу показывается на странице без перезагрузки.

## Live-процесс резервного копирования

- Добавлен раздел «Процесс бэкапа · live» на странице журналов.
- Отображается создание архива, подготовка баз, упаковка, отправка в Telegram, отправка на Яндекс.Диск и итоговый результат.
- Состояние хранится в небольшом атомарном JSON-файле; веб-панель опрашивает его раз в секунду только при открытом live-разделе и реже при скрытой вкладке.
- Содержимое live-журнала ограничено последними 60 событиями и не содержит секретов.

## Проверка

- Целевые backup/WebDAV regression-тесты: 21 passed.
- Python syntax/compile checks: passed.
- Рабочие базы, подписки, оплаты и API 3x-ui не изменялись.
