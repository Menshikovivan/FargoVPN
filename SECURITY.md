# Безопасность FargoVPN

## Поддерживаемая версия

Текущий релиз проекта: **5.0.4**. Для production рекомендуется использовать актуальный архив релиза и проверять его SHA-256 перед установкой.

## Секреты

Не публикуйте Telegram Bot Token, ключи API 3x-ui, пароль PostgreSQL, `WEB_SECRET_KEY`, VAPID private key, cookies и production-конфигурацию. При утечке секрета его следует немедленно отозвать/заменить и проверить журналы доступа.

## Сообщение об уязвимости

Не размещайте чувствительные данные об уязвимости в публичных issue. Для закрытого сообщения используйте контакт правообладателя проекта и приложите минимальный воспроизводимый сценарий без production-секретов.

## Безопасная установка

Перед установкой проверяйте источник архива и SHA-256. Не запускайте неизвестные `install.sh` или восстановление backup на production-сервере без предварительной проверки содержимого.
