# VPN Service Platform

**Готовая платформа для продажи и сопровождения VPN‑подписок «под ключ»**: Telegram‑бот для клиентов, веб‑панель администратора, интеграция с **3x‑ui**, приём платежей с автоматической проверкой чеков (OCR), резервное копирование, массовые рассылки и самообновление через GitHub Releases.

Проект рассчитан на self-hosted установку на собственный VPS одной командой (`install_with_web.sh`) и предназначен для тех, кто продаёт доступ к VPN небольшой аудитории и хочет автоматизировать выдачу подписок, приём оплаты и поддержку клиентов через Telegram.

---

## Возможности

### 🤖 Telegram‑бот для клиентов
- Inline‑меню (без устаревшей `ReplyKeyboardMarkup`) с разделами «Моя подписка», «Купить/продлить VPN», FAQ и связь с администратором.
- Инструкции по подключению для приложений **Incy** и **HApp**, раздел «если VPN не подключается».
- Приём чека об оплате прямо в чате, статус подписки и оставшийся трафик.
- Идентификация пользователя строго по Telegram ID (username считается изменяемым и не используется как ключ).

### 🛠 Админ‑панель бота (в Telegram)
- Управление пользователями, ручная выдача доступа, подтверждение/отклонение платежей.
- Синхронизация с 3x‑ui и запуск массовой рассылки прямо из чата.

### 🖥 Веб‑панель администратора
- **Пользователи** — список, карточка пользователя, создание, продление, привязка Telegram, блокировка, удаление, импорт учётных записей из старой базы (с превью перед применением).
- **Платежи** — очередь чеков, просмотр присланного изображения, подтверждение/отклонение.
- **Рассылки** — массовая отправка сообщений и медиа по базе подписчиков в фоне.
- **Мониторинг и диагностика** — состояние базы, хранилища, трафика, уведомлений и обновлений; перезапуск сервисов.
- **Резервные копии** — создание, скачивание, восстановление и удаление бэкапов из панели.
- **Логи** — просмотр журналов systemd-сервисов без выхода в консоль.
- **Настройки** — параметры сервиса, оплаты, OCR-проверки чеков, Яндекс.Диска и обновлений.
- Встроенный чат с историей переписки и непрочитанными сообщениями, общий для бота и панели.

### 💳 Приём оплаты и проверка чеков (OCR)
- Локальное распознавание банковских квитанций (`pytesseract`, рус/eng) без передачи данных во внешние сервисы.
- Настраиваемые правила автоподтверждения: сумма, получатель (с алиасами), статус операции, срок давности чека, защита от повторной отправки одного и того же чека.
- OCR используется как вспомогательная эвристика — сомнительные платежи остаются в очереди на ручную проверку.

### 🔌 Интеграция с 3x‑ui
- Трафик, срок действия и last-online считаются авторитетными данными 3x‑ui; локальная SQLite‑база — только кэш и метаданные для бота.
- Периодическая синхронизация клиентов между ботом и панелью 3x‑ui.

### 💾 Резервное копирование
- Локальные архивы + доставка в Telegram (частями), на **Яндекс.Диск** (OAuth REST API или локальный WebDAV‑диск) и через `rclone` (легаси‑способ).
- Расписание по интервалу, автоочистка старых копий, повторные попытки при сбое, восстановление из панели.

### 🔄 Самообновление и откат
- В версии 3.0 единственный источник обновлений — **GitHub Releases**: панели проверяют последний опубликованный релиз указанного репозитория, скачивают архив и проверяют его SHA‑256, размер, версию, структуру и защиту от path traversal перед установкой.
- Публикация релиза (включая загрузку архива и changelog) доступна прямо из веб‑панели для выделенного администратора-издателя.
- Перед обновлением создаётся проверенная резервная копия — при ошибке выполняется автоматический откат (rollback).

### 🔐 Безопасность
- CSP, HSTS (при HTTPS), `X-Content-Type-Options`, `X-Frame-Options`, Referrer/Permissions Policy, защита от CSRF.
- Ограничение попыток входа по IP и логину с нарастающей блокировкой, хранится в SQLite.
- Constant-time сравнение секретов на уровне UTF‑8 байт — логин/пароль веб‑панели поддерживают кириллицу и Unicode без ошибок сравнения.
- Медиафайлы переписки отдаются только через авторизованный маршрут с проверкой владельца события и сигнатуры содержимого; бинарные данные не хранятся в SQLite.
- Токен обновлений (`UPDATE_API_TOKEN`) и роль издателя, привязанная к конкретному логину; загрузка обновлений — только с origin настроенной главной панели.
- Подробности — в [`SECURITY.md`](SECURITY.md).

## Технологии

| Компонент | Стек |
|---|---|
| Telegram‑бот | Python, [aiogram 3](https://docs.aiogram.dev/) |
| Веб‑панель | Python, [FastAPI](https://fastapi.tiangolo.com/) + Uvicorn |
| База данных | SQLite (через `aiosqlite`) |
| OCR чеков | Tesseract (`pytesseract`), Pillow |
| HTTP‑клиент | `httpx`, `aiohttp` |
| Развёртывание | systemd‑юниты, установочные bash‑скрипты |

## Требования

- Linux‑сервер (VPS) с systemd и правами root для установки.
- Установленная и настроенная панель **3x‑ui** с API‑доступом.
- Telegram Bot Token.
- Python 3.10+ (разворачивается установщиком в отдельном виртуальном окружении).

## Установка

Новая установка:

```bash
cd /root
tar -xzf VPN_Service_Platform_3.0.0_FULL.tar.gz
cd VPN_Service_Platform_3.0.0_FULL
sudo bash install_with_web.sh
```

Установщик запросит параметры бота, панели и сервиса, создаст рабочий каталог `/root/vpn_bot`, виртуальное окружение и systemd‑сервисы `vpn-service-bot` и `vpn-service-web`.

Обновление существующей установки:

```bash
sudo bash install_with_web.sh --update-existing /root/vpn_bot
```

При обновлении сохраняются `config.py`, база данных, пользователи, платежи, настройки обновлений и текущее виртуальное окружение.

Также доступны `install_bot_only.sh` (только бот, без веб‑панели) для облегчённых установок.

## Проверка после установки

```bash
curl -fsS http://127.0.0.1:8088/health
sudo systemctl status vpn-service-bot vpn-service-web --no-pager
sudo journalctl -u vpn-service-web -n 100 --no-pager
```

Ожидаемая версия эндпоинта `/health`: `3.0.0`.

## Диагностика и обслуживание

```bash
# Общая диагностика (база, хранилище, обновления, трафик)
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/diagnostics.py --live --json

# Принудительный бэкап и проверка подключения к Яндекс.Диску
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/backup.py --force
sudo /root/vpn_bot/.venv/bin/python /root/vpn_bot/backup.py --test-yandex
```

Полный список команд — в [`COMMANDS.md`](COMMANDS.md).

## Структура проекта

```
├── app/
│   ├── main.py              # Telegram-бот
│   ├── webapp.py             # Веб-панель (FastAPI)

│   │   ├── receipt_ocr.py     # OCR и проверка чеков
│   │   ├── media.py           # Обработка медиа Telegram
│   │   └── telegram_events.py # Журнал переписки
│   ├── backup.py             # Резервное копирование
│   ├── update_manager.py     # Публикация и установка обновлений
│   ├── rollback_worker.py    # Откат к предыдущей версии

│   ├── diagnostics.py        # Диагностика системы
│   └── auth_security.py      # Защита входа в панель

└── tests/                    # Регрессионные и модульные тесты
```
