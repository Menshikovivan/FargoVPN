# FargoVPN 4.5.1

## Обновление через GitHub

- Разделены публикация релиза в GitHub и его установка на главной панели.
- Кнопка «Загрузить обновление в GitHub» больше не запускает установку автоматически.
- После публикации архив сохраняется локально в каталоге обновлений и становится доступен отдельной кнопке «Установить».
- Установка опубликованного архива выполняется только после явного действия администратора.
- Сохранён существующий безопасный detached/systemd-механизм обновления и проверка архива.
