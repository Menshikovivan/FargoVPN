# FargoVPN 4.7.6

## Исправлено

- Сохранён и проверен сквозной журнал исходящих сообщений из веб-панели: успешная отправка пользователю записывается в `user_events` с направлением `out`, поэтому сообщение появляется во вкладке «Сообщения» вместе с входящими и служебными событиями.
- Исправлен HTTP 500 после успешной отправки из веб-панели: сбой вспомогательного `message_log` или подготовки UI-ответа больше не превращает успешно доставленное Telegram-сообщение в ошибку.
- Отправка фото/видео из панели также записывается в общий журнал исходящих событий.
- Закрыт SSRF в Web Push: endpoint подписки принимается только по HTTPS и должен разрешаться только в глобально маршрутизируемые адреса. Loopback/private/link-local/локальные DNS-результаты и URL с учётными данными отклоняются.
- Push-доставка больше не следует HTTP-редиректам, чтобы исключить обход проверки endpoint через редирект во внутреннюю сеть.

## Проверка

- Регрессионный набор FargoVPN: 65/65 тестов.
- Отдельно проверены контракт журнала сообщений, unread/pagination/filtering, безопасное восстановление tar.gz и SSRF-защита Push.
