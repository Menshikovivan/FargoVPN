# FargoVPN 4.8

## Исправление резервного копирования

- Исправлен критический баг Telegram-доставки резервной копии: успешная отправка документа больше не считается неудачной из-за ошибки `message_journal`.
- Запись служебного события `message_journal` теперь выполняется в режиме best-effort и не может запустить повторную отправку уже доставленного файла.
- Устранён сценарий трёх одинаковых документов: раньше после успешного `send_document()` происходил `NameError`, после чего одна и та же часть отправлялась повторно до трёх попыток.
- Сводка результата бэкапа также не зависит от доступности журнала сообщений.

## Планировщик

- Плановый бэкап по-прежнему выполняется только через единый `vpn-service-backup.timer` → `vpn-service-backup.service`.
- При установке/обновлении сохраняется одна каноническая служба и таймер; старые FargoVPN/vpn-bot backup units и ссылки из cron удаляются через встроенный аудит служб.
- `flock`/внутренний backup lock остаётся защитой от параллельного запуска.

## Совместимость

- Схема базы данных не меняется.
- Формат архивов остаётся обычным `.tar.gz`.
- Внешний Nginx и маршрутизация 3x-ui не изменяются.
