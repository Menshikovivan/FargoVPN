# FargoVPN 4.5.3

## Изменения

- Исправлена публикация веб-панели FargoVPN при установке на сервер, где Nginx/L4/3x-ui заранее развёрнуты внешним проектом `Itman75/Nginx-L4-Stream-Router-Mask-for-3x-ui`.
- FargoVPN по-прежнему не устанавливает и не заменяет Nginx: добавляется только собственный секретный URI в существующий HTTPS virtual host.
- После успешной установки установщик автоматически определяет домен из фактически загруженной конфигурации Nginx и выводит готовую HTTPS-ссылку на веб-панель.
- Найденный домен и публичный URL сохраняются в `config.py`, поэтому ссылка корректно отображается и после обновления.
- Исправлена совместимость с фактическим Unix-сокетным HTTPS listener внешнего проекта (`/dev/shm/nginx-http.sock` + `127.0.0.1:9443`).
- Проверки установки и внешний Nginx route усилены тестами.
