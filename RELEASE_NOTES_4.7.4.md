# FargoVPN 4.7.4

## Исправлено
- Критический регресс веб-панели: раздел «Сообщения» больше не возвращает `Internal Server Error`.
- Исправлена ошибка порядка инициализации `unread_map` в `messages_page()`, возникавшая при наличии хотя бы одного диалога.
- Список диалогов теперь строится после подтверждения прочтения выбранного чата и обновления unread-снимка.

## Совместимость
- Схема БД не меняется.
- Журнал сообщений, фильтры, поиск, пагинация, счётчик и Telegram API journal остаются без изменений.
