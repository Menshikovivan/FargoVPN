# FargoVPN 4.4.0

## Массовая рассылка

Исправлена ошибка `Недействительный CSRF-токен` при запуске массовой рассылки. Страница рассылки использует отдельный XHR для прогресса загрузки вложения; теперь этот XHR передаёт тот же session CSRF-токен, который сервер проверяет для всех POST-запросов панели. Защита CSRF не отключалась.

## Резервное копирование

Плановый бэкап продолжает запускаться через `vpn-service-backup.timer` с worker `backup.py --scheduled`. Кнопка `💾 Бэкап` в Telegram-админке запускает тот же worker в режиме `--force`, поэтому ручной запуск не зависит от трёхдневного интервала. Очередь доставки и проверка Яндекс.Диска остаются общими для обоих способов запуска.

## Проверка релиза

- 3 version markers синхронизированы на `4.4.0`.
- Добавлена регрессия на CSRF-заголовок XHR рассылки.
- Добавлены контрактные проверки systemd backup service/timer и Telegram manual backup.
- Устаревший тест WebDAV приведён к текущему WebDAV API.
- PostgreSQL backup contract приведён к фактическому имени `databases/fargovpn.sql`.
