# FargoVPN 4.5

## Аудит и стабильность

- Добавлены timeout, ограничение параллельных запросов и безопасные retry/backoff для запросов чтения к 3x-ui.
- Добавлен процессный кэш списка включённых inbound и single-flight обновление.
- Добавлен `/healthz` без обращения к внешним компонентам.
- Плановый backup запускается один раз в сутки в 03:30.

## Новая настройка 3x-ui

В разделе настроек можно выбрать несколько включённых inbound. Выбор применяется только к новым клиентам/подпискам. Существующие клиенты не перебиндиваются.

Если настройка не задана, используется обратимое поведение 4.4.10: все включённые inbound. Если часть сохранённых ID больше не существует или отключена, доступны только оставшиеся; если не осталось ни одного, создание нового клиента завершается понятной ошибкой.

## Удаление внешнего backup-канала

В 4.5 отсутствуют runtime-код, UI/API, конфигурация и системные задания удалённого канала. `scripts/cleanup_legacy_remote_backup.sh` удаляет legacy-настройки на уже установленных серверах.

## Совместимость

- Схема 3x-ui не изменяется.
- Destructive migration PostgreSQL не выполняется.
- Секреты не включаются в архив.
