# FargoVPN 4.4.10

## Изменения

- Новые клиенты 3x-ui получают все включённые inbound по умолчанию.
- После создания FargoVPN перечитывает ClientRecord и проверяет фактические inbound; отсутствующие привязки восстанавливаются через `/panel/api/clients/{email}/attach`.
- `XUI_MANAGED_INBOUND_IDS` остаётся опциональным явным allowlist. Пустой список означает все включённые inbound.
- В карточке пользователя добавлено поле ручного комментария/имени. Оно хранится в `users.notes` и синхронизируется с `comment` клиента 3x-ui.
- Комментарий из 3x-ui подтягивается обратно в карточку FargoVPN.
- Telegram ID и `username` остаются отдельными идентификационными полями и не меняются при редактировании комментария.
