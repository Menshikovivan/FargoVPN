# FargoVPN 4.7.1

## Исправлено

- Полностью восстановлен рабочий механизм changelog для GitHub Release: релизный файл `RELEASE_NOTES_4.7.1.md` теперь присутствует в пакете и используется как основной источник текста описания релиза.
- Исправлено отображение changelog в разделе «Обновления» панели: добавлена совместимость с `INSTALLED_CHANGELOG.md`, `RELEASE_NOTES_<version>.md` внутри приложения и секциями текущей версии из `CHANGELOG.md`.
- Исправлено извлечение секции версии из `CHANGELOG.md`: устранено двойное экранирование регулярного выражения, из-за которого секция `## 4.7` ранее не находилась.
- Исправлена публикация changelog в публичную ветку GitHub: `RELEASE_NOTES_<version>.md` с актуальной версией снова входит в синхронизируемую публичную поверхность.
- Сохранены все исправления 4.7: сохранение «Дни напоминаний» и «Кэш 3x-ui», корректное использование задержки Telegram-рассылки, корректная обработка недоставленных сообщений, неблокирующий отчёт подписок и ограничение хранения резервных копий `config.py`.
- Сохранены исправления 4.6.16: стабильное создание полного backup, корректная обработка корневой записи tar, очистка шумовых systemd-вызовов template units, безопасный users-only restore и отсутствие дублирующего восстановления `config.py`.

## Добавлено

- `INSTALLED_CHANGELOG.md` — установленная копия release notes для гарантированного отображения changelog после установки/обновления.
- `INSTALLED_CHANGELOG_VERSION` — явный marker установленной версии для центра обновлений.
- Регрессионные проверки контракта changelog: наличие release notes, корректность секции `CHANGELOG.md`, version markers и наличие данных для GitHub Release body.

## Изменено

- Версия FargoVPN повышена до `4.7.1` во всех основных version markers и README.
- При чтении changelog приоритет отдан точному `RELEASE_NOTES_<version>.md`, затем установленной копии, затем секции соответствующей версии в `CHANGELOG.md`; legacy `RELEASE_NOTES_*.md` остаются fallback.
- Публикация GitHub Release и синхронизация `main` используют один и тот же проверенный текст release notes.

## Совместимость

- Структура PostgreSQL и 3x-ui БД не изменяется.
- Миграции базы данных для 4.7.1 не требуются.
- Существующая схема оплаты и 4-значные referral-коды не изменяются.
- Внешний Nginx/L4 Router не изменяется и не включается в управление FargoVPN.
