# FargoVPN 4.3.4

## Публикация и установка из главной панели

Одна загрузка нового `.tar.gz` в главной веб-панели теперь проходит единым сценарием: проверка архива → GitHub Release → синхронизация публичной `main` → установка того же проверенного локального архива.

Если Release или синхронизация `main` не завершились успешно, установка не запускается и операция возвращает ошибку.

## Автоматическая публикация main

После успешной публикации GitHub Release из веб-панели FargoVPN автоматически заменяет публичное содержимое ветки `main` текущей версией.

Публичная поверхность `main` включает только bootstrap `install.sh`, полный `FargoVPN_FULL.tar.gz`, checksum, README, VERSION, LICENSE, CHANGELOG, release notes, SECURITY и `.gitignore`.

Публикация выполняется одним Git commit без force-push. При конфликте ветки `main` новый commit не применяется, а уже опубликованный Release остаётся доступен.


## 4.3.4 patch

- Исправлен endpoint GitHub REST API для финального обновления ветки `main`: PATCH теперь использует `/git/refs/heads/main`.
- Добавлен контрактный тест, исключающий повторение ошибки `HTTP 404` на шаге переключения `main`.
